# ইম্পোটেক স্টোর — React ই-কমার্স (v3)

চায়না থেকে আমদানি করা বাইক অ্যাকসেসরিজের জন্য সম্পূর্ণ React ই-কমার্স ফ্রন্টএন্ড।
ডার্ক প্রিমিয়াম থিম + অ্যাম্বার অ্যাকসেন্ট, আর একটি **সম্পূর্ণ অ্যাডমিন প্যানেল** যেখান থেকে
প্রোডাক্ট, অর্ডার, ক্যাটাগরি, কুপন, রিভিউ, হোম পেজ, মেনু, কনটেন্ট, থিম, SEO — সব কিছু
কোড ছাড়াই ম্যানেজ করা যায়।

> **v3-এ নতুন:** ১৪টি নতুন অ্যাডমিন সেকশন, অর্ডার সিস্টেম, কুপন, কনটেন্ট পেজ, থিম কন্ট্রোল,
> SEO, ব্যাকআপ/রিস্টোর, এবং প্রোডাক্ট ভিডিও অটো-প্লে।

---

## 🚀 রান করার নির্দেশনা

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল
npm install

# ২. ডেভ সার্ভার চালু (http://localhost:5173)
npm run dev

# ৩. প্রোডাকশন বিল্ড (dist/ ফোল্ডারে)
npm run build

# ৪. বিল্ড প্রিভিউ
npm run preview
```

প্রয়োজন: **Node.js 18+** (তৈরি ও টেস্ট করা হয়েছে Node 20-এ)।

## 🧱 টেক স্ট্যাক

| স্তর | ব্যবহৃত টুল |
|------|-------------|
| UI | React 18 |
| বিল্ড | Vite 5 |
| রাউটিং | react-router-dom v6 |
| স্টেট ম্যানেজমেন্ট | Redux Toolkit + react-redux |
| আইকন | react-icons (Feather সেট) |
| স্টাইল | প্লেইন CSS — প্রতি কম্পোনেন্টের আলাদা ফাইল |
| ফন্ট | Hind Siliguri (বাংলা) + Inter |

> রেফারেন্স প্রজেক্টটি (react-e-commerce--main.zip) **CRA + react-router-dom v6 +
> Redux Toolkit** প্যাটার্নে ছিল — প্রতি কম্পোনেন্টের নিজস্ব CSS ফাইল, `src/productsStore/`
> -এ সেন্ট্রাল ডেটা, `src/redux-state/`-এ slice ফাইল। একই আর্কিটেকচার রাখা হয়েছে;
> শুধু CRA-এর জায়গায় Vite ব্যবহার করা হয়েছে (দ্রুততর ডেভ ও বিল্ড)।

## 🆕 v3-এ যা যোগ হয়েছে

- **অর্ডার সিস্টেম** — চেকআউটে অর্ডার প্লেস করলে `useOrders`-এ সেভ হয়, অ্যাডমিনে দেখা যায়,
  `/track`-এ আসল অর্ডার আইডি দিয়ে স্ট্যাটাস ট্র্যাক করা যায়।
- **কুপন** — চেকআউটে কুপন কোড প্রয়োগ, ভুল/মেয়াদোত্তীর্ণ হলে বাংলায় কারণ দেখায়।
- **কনটেন্ট পেজ** — About/Privacy/Terms/Return/FAQ, সবই অ্যাডমিন থেকে এডিটযোগ্য।
- **থিম কন্ট্রোল** — অ্যাকসেন্ট কালার, ফন্ট স্কেল, রেডিয়াস, ডার্ক/লাইট — CSS ভেরিয়েবলে প্রয়োগ।
- **SEO** — প্রতি রাউটে ডাইনামিক টাইটেল + মেটা ডেসক্রিপশন + OG ট্যাগ।
- **ব্যাকআপ/রিস্টোর** — এক ক্লিকে পুরো সাইটের ডেটা JSON-এ এক্সপোর্ট, আবার ইমপোর্ট।
- **ভিডিও অটো-প্লে** — প্রোডাক্টে টগল করলে ডিটেইল পেজে ভিডিও muted অবস্থায় স্বয়ংক্রিয়ভাবে
  চলে, ইউজার চাইলে সাউন্ড চালু করতে পারে।
- **কনফিগ-চালিত ফ্রন্টএন্ড** — Navbar, Footer, HeroSlider, CategoryStrip, BannerGrid,
  Services, Newsletter সবই এখন অ্যাডমিন কনফিগ থেকে পড়ে।

## 💾 ডেটা ও স্টেট

সব ডেটা **ব্রাউজারের `localStorage`**-এ থাকে (কোনো ব্যাকএন্ড লাগে না)। কী-গুলো:

| কী | কী রাখে |
|----|--------|
| `impotech_products` | প্রোডাক্ট ক্যাটালগ (অ্যাডমিন এডিট করলে) |
| `impotech_categories` | ক্যাটাগরি লিস্ট + ক্রম |
| `impotech_orders` | চেকআউট থেকে আসা অর্ডার |
| `impotech_coupons` | কুপন কোড |
| `impotech_reviews` | প্রোডাক্ট রিভিউ |
| `impotech_site` | সাইট কনফিগ (identity, theme, nav, contact, checkout, home, content, seo, admin) |
| `impotech_bg` | ব্যাকগ্রাউন্ড সেটিংস |
| `impotech_cart` | কার্ট (Redux persist) |
| `impotech_wishlist` | উইশলিস্ট |

- প্রতিটি স্টোর সেভ হলে একটি কাস্টম ইভেন্ট ফায়ার করে, আর `storage` ইভেন্টও শোনে —
  তাই **একই ব্রাউজারের অন্য ট্যাবে বদলালেও সাথে সাথে প্রয়োগ হয়**।
- **ব্যাকআপ ট্যাব** থেকে সব কী একসাথে JSON-এ এক্সপোর্ট/ইমপোর্ট করা যায়।

- [ ] **সার্ভার-সাইড অথেন্টিকেশন** — অ্যাডমিন পাসওয়ার্ড এখন শুধু ক্লায়েন্ট-সাইড, যে কেউ
      সোর্স কোড পড়ে বাইপাস করতে পারে। JWT/session দরকার।
- [ ] **পেমেন্ট গেটওয়ে** — বিকাশ/নগদ/রকেট মার্চেন্ট API, অথবা SSLCommerz / Stripe
- [ ] **অর্ডার নোটিফিকেশন** — নতুন অর্ডার এলে SMS/ইমেইল/হোয়াটসঅ্যাপ অ্যালার্ট

### 🟡 গুরুত্বপূর্ণ
